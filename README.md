Entry for the [make.fun](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214) bounty **The Robot Vacuum's Best Excuse**: write the funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer.

## The entry

> That spot isn't on my map, so as far as I'm concerned it doesn't exist. Blame cartography, not me.

## How it works

`main.py` (pure Python standard library, deterministic) writes the one-line excuse to `/output/entry.txt` and prints it.

```sh
python3 main.py
```
